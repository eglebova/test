Новая версия сайта адвоката Елены Глебовой

Исходники сайта находятся в каталоге project/. Корневые HTML-файлы, assets, robots.txt и sitemap.xml — актуальная тестовая preview-сборка из project/. Корневая копия — preview-сборка. Сборку следует выполнять вручную скриптом project/scripts/build.py; автоматический GitHub Actions workflow в репозитории не настроен.

ВАЖНО: корневая preview-сборка сформирована с тестовым origin https://qa.invalid, содержит noindex,nofollow и закрывающий robots.txt. Она предназначена для проверки изменений и НЕ является production-релизом. Перед размещением на реальном домене соберите production-комплект:
  python3 project/scripts/build.py --origin https://ВАШ-ДОМЕН.ru --out ./production
После успешной проверки загрузите содержимое production/ в корневой каталог сайта. Не загружайте весь репозиторий или каталог project/ на хостинг.

На странице вознаграждения:
- «Предварительная беседа по телефону» — бесплатно. Это краткое организационное обсуждение общей категории обращения, возможного объёма правовой помощи и стоимости; беседа не является юридической консультацией и не включает изучение документов или рекомендации по существу.
- «Юридическая консультация (до 1 часа)» — 3 500 рублей.
- Таблица использует предметные формулировки: подготовка, анализ, экспертиза, представительство, сопровождение. Количество и состав ценовых позиций не расширялись.

Форма обращения через сайт удалена. На странице /contacts/ оставлены прямые способы связи: телефон, электронная почта и MAX. Сайт не собирает через контактные поля имя, телефон, адрес электронной почты или описание дела; посетитель самостоятельно инициирует звонок либо открывает внешний почтовый клиент или MAX.

В разделе «Мои материалы» размещены тринадцать авторских публикаций. Публикация по ЗоЗПП помечена как предварительная: ряд реквизитов в исходном тексте требует проверки по полным судебным актам. Не цитируйте непроверенные дела как достоверную судебную практику.
