Новая версия сайта адвоката Елены Глебовой

В корне архива находится готовая статическая публичная сборка: index.html, каталоги страниц, assets, sitemap.xml, robots.txt и серверные правила. Ее можно использовать для локального просмотра.

ВАЖНО: текущая сборка сформирована с тестовым origin https://qa.invalid и закрыта от индексации. Перед размещением на реальном домене пересоберите сайт командой:
  python3 project/scripts/build.py --origin https://ВАШ-ДОМЕН.ru --out ./production
После проверки загрузите содержимое production/ в корневой каталог сайта.

Контактная форма на странице /contacts/ не отправляет данные на сервер: она формирует черновик письма в почтовой программе посетителя. Доставка зависит от настроек его устройства. Для полноценной серверной формы требуется отдельный этап проектирования обработки персональных данных и защиты.

Три новые статьи добавлены в раздел «Мои материалы». Публикация по ЗоЗПП помечена как предварительная: ряд реквизитов в исходном тексте требует проверки по полным судебным актам. Не цитируйте непроверенные дела как достоверную судебную практику.
