- [x] Добавлена ссылка «Наверх» на страницах.
- [x] Добавлены шаблоны защитных HTTP-заголовков для Nginx, Caddy и Apache.
- [x] Настроена выдача `index.html` для каталогов в шаблонах серверной конфигурации.
- [x] Скрипт сборки проверяет внутренние ссылки, допустимость формы и локального скрипта, встроенный контент, meta refresh и inline event handlers.
- [x] В сборке добавлены компактная нативная мобильная навигация и единое пояснение о бесплатной предварительной беседе и платной консультации.

## Блокеры до production

- [ ] Выбрать домен; после этого сформировать canonical, `og:url`, sitemap и DNS для production.
- [ ] Проверить ФИО, статус и реестровую запись в действующем официальном источнике.
- [ ] Подтвердить точное наименование адвокатского образования и его реестровые сведения.
- [ ] Подтвердить адрес адвокатского образования и определить, какие сведения об адресе подлежат размещению. Адрес не добавлен в сайт, поскольку его публикация требует отдельного согласования владельцем и проверки позиции АПМО. Пункт 2.3 Рекомендаций ФПА РФ от 15.09.2022 относит адрес к обязательной информации персонального сайта адвоката.
- [ ] Проверить сведения об образовании, дате начала адвокатской деятельности, телефон и электронную почту.
- [ ] Подтвердить право на публичное размещение предоставленной фотографии.
- [ ] Утвердить тексты сайта лично адвокатом: редакторская проверка выполнена, но она не заменяет ответственность владельца за содержание сайта.
- [ ] Выбрать инфраструктуру и проверить фактическую географию хранения контента, технических логов и резервных копий.
- [ ] Определить оператора, цели и правовые основания обработки технических данных посещения; проверить необходимость уведомления Роскомнадзора и при необходимости подготовить политику обработки персональных данных, соответствующую фактическим потокам.
- [ ] Настроить HTTPS, firewall, MFA, доступы, обновления, резервное копирование и периодический тест восстановления.
- [ ] Применить серверную конфигурацию. Проверить, что `/`, `/about/`, `/practice/` и другие адреса разделов открывают `index.html`, а не индекс каталога или интерфейс файлового хранилища.
- [ ] Проверить реальный сайт в нескольких браузерах, на мобильных устройствах и через внешние TLS/header/security scanners.

## Ограничения проверки

Контактная форма не является серверной: она формирует черновик `mailto:`. Пользователь должен самостоятельно проверить и отправить письмо. Отсутствие серверного backend не означает, что доставка подтверждена.

Локальная статическая сборка не содержит серверной логики, API или серверных обработчиков; единственный локальный JavaScript используется для подготовки черновика письма на странице контактов. Поэтому в релизе 1 отсутствуют клиентские точки ввода и обработчики, которые можно было бы тестировать на SQL-инъекции, XSS через формы, CSRF или загрузку вредоносных файлов. Это снижает поверхность атаки, но не заменяет внешний тест сервера, хостинга, DNS, TLS, учетных записей, панели управления и резервных копий.

Не заявлять «полностью защищено», «неуязвимо», «прошло pentest» или «соответствует всем требованиям» без соответствующей внешней проверки.
